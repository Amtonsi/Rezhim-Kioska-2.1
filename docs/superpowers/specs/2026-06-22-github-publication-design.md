# Публикация проекта «Режим Киоска» на GitHub

## Цель

Опубликовать последнюю проверенную рабочую версию проекта в публичном GitHub-репозитории вместе с полным исходным кодом, русской документацией и готовыми сборками для поддерживаемых версий Windows.

## Репозиторий

- Имя репозитория: `Rezhim-Kioska`.
- Отображаемое название: «Режим Киоска».
- Видимость: публичный.
- Язык документации и описания: русский.
- Лицензия: MIT.
- Автор: Абдрахманов Амаль Даулетович.

## Состав публикации

В Git-репозиторий входят:

- исходный код последней рабочей Modern- и Legacy-версии;
- конфигурационные схемы и шаблоны;
- скрипты сборки, установки и восстановления;
- автоматические тесты;
- русская документация;
- изображения основных пользовательских сценариев.

Временные каталоги сборки, локальные журналы, виртуальные окружения и другие машинно-зависимые файлы в репозиторий не включаются.

## Готовые сборки

Готовые архивы публикуются как вложения GitHub Release `v2.0.0`, а не сохраняются в истории Git:

- Modern для Windows 7 SP1 и новее;
- Legacy x86 для Windows XP SP1–SP3 и Windows Server 2003.

Каждый архив должен содержать все необходимые файлы запуска и контрольную сумму SHA-256. Legacy-архив распространяется целиком: отдельный EXE без расположенных рядом библиотек и каталогов не считается переносимой сборкой.

## Главная страница

Корневая `README.md` одновременно является описанием GitHub-проекта и основной инструкцией. Она содержит:

1. назначение программы и модель безопасности;
2. таблицу выбора Modern/Legacy;
3. требования к отдельной операторской учётной записи;
4. загрузку и первый запуск;
5. выбор и сохранение разрешённого приложения;
6. работу операторского режима;
7. разблокировку локальной учётной записью администратора Windows;
8. смену разрешённого приложения;
9. Restore/Undo и аварийное восстановление;
10. сборку из исходного кода;
11. ограничения Windows XP, Server 2003 и Home-редакций;
12. лицензию и авторство.

Иллюстрации хранятся в `docs/images/` и не содержат паролей, персональных данных или кадров с ранее исправленными ошибками.

## Проверка перед публикацией

Перед отправкой на GitHub необходимо:

- проверить точный состав изменений и исключить посторонние файлы;
- выполнить актуальные Modern- и Legacy-тесты;
- проверить наличие обязательных файлов внутри релизных архивов;
- проверить SHA-256 готовых архивов;
- убедиться, что README корректно отображает русский текст и изображения;
- убедиться, что пароль администратора, журналы и локальные секреты не попали в историю;
- убедиться, что рабочий стол основной учётной записи не изменён после проверок.

## Публикация

Последовательность публикации:

1. Создать публичный репозиторий `Rezhim-Kioska`.
2. Отправить проверенный исходный код основной веткой.
3. Настроить краткое русское описание и темы репозитория.
4. Создать релиз `v2.0.0` с русским описанием.
5. Приложить Modern- и Legacy-архивы и файл контрольных сумм.
6. Проверить ссылки на скачивание и отображение README на GitHub.

## Неизменяемые условия

- Публикуется только последняя версия, подтверждённая пользователем как рабочая.
- Рабочая логика Modern и Legacy не переписывается ради публикации.
- Исходный код обеих сборок обязателен.
- Сборочные артефакты не должны заменять исходный код.
- Основная учётная запись и рабочий стол ноутбука не переводятся в режим киоска во время подготовки публикации.
