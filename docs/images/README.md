# Изображения интерфейса

Изображения созданы 22 июня 2026 года из актуальных модулей интерфейса
`v2/modern/kiosk_v2_modern/ui/scene.py` и
`v2/modern/kiosk_v2_modern/ui/tk_view.py`.

Для съёмки использовалось безопасное демонстрационное окно без запуска
keyboard hook, завершения Explorer, изменения shell и применения политик.

- `01-main-screen.png` - операторский экран с разрешённым приложением.
- `02-admin-login.png` - окно локальной авторизации администратора Windows.
- `03-admin-session.png` - ограниченная административная сессия киоска.

На изображениях нет паролей, токенов, журналов, персональных файлов и данных
пользователя. Снимок стандартного диалога выбора EXE не включён, потому что его
содержимое зависит от версии Windows и локальных файлов пользователя.
