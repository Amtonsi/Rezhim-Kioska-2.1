Режим Киоска 2.1.0

1. Распаковываем весь комплект в постоянную папку локального диска с NTFS.
   Для рабочей установки администратор создаёт папку в Program Files.
   Оператору достаточно прав чтения и запуска. Рядом с загрузчиком должны
   лежать Restore.exe, Configurator.exe и папка config. В Legacy сохраняем
   также все DLL и папки из архива. Самораспаковывающийся EXE извлекает файлы.

2. Создаём отдельную стандартную локальную учётную запись KioskOperator,
   входим в неё один раз. Если имя другое, администратор меняет operatorUser
   в config\kiosk.v2.json. Сохраняем отдельную административную учётную запись.

3. Для проверки запускаем RezhimKioska-V2-Modern.exe или
   RezhimKioska-V2-Legacy.exe с параметрами --platform-check и --check-config
   по очереди. Код 0 означает, что соответствующая проверка пройдена.

4. Входим в отдельный сеанс оператора. Запускаем загрузчик без параметров.
   Нажимаем «Разблокировать», вводим имя и пароль локального администратора.
   Через «Изменить приложение» выбираем установленную программу. В защищённой
   папке для записи настроек Windows может повторно запросить учётные данные.

5. Закрываем программу и проверяем её повторный запуск. Сворачиваем окно
   и нажимаем «Развернуть приложение». Для завершения ручного режима
   проходим административную проверку и выбираем «Открыть рабочий стол».

6. Порядок постоянной установки и отмены, команды и результаты по версиям
   Windows приведены в README и документах репозитория.
   https://github.com/Amtonsi/Rezhim-Kioska-2.1
   Исходная версия: https://github.com/Amtonsi/Rezhim-Kioska
