# Проверка Legacy на XP и Server 2003

> Этот документ относится к предыдущим выпускам. Для версии 2.1 используем [инструкцию по установке и откату](../README.md) и [протокол испытаний в VMware](VMWARE-2.1.md).

Обязательные VM: Windows XP SP1 x86, Windows XP SP3 x86 и Windows Server 2003 x86. Для каждого случая используйте отдельный снимок VM и отдельную операторскую УЗ без прав администратора.

## До теста

1. Создайте чистый снимок VM.
2. Запишите версию ОС, SID оператора, shell администратора и оператора.
3. Сохраните списки служб, драйверов и автозагрузки.
4. Убедитесь, что оператор не входит в локальную группу Administrators.
5. Войдите оператором один раз для создания `NTUSER.DAT`, затем вернитесь в административную УЗ.
6. Скопируйте Legacy EXE и config в защищённый каталог, доступный оператору только на чтение/выполнение.

## Сценарий

1. Выполните `install` без `--apply` и проверьте dry-run.
2. Выполните backup и `install --apply` из административной УЗ.
3. Войдите оператором: первым должен стартовать `RezhimKioska-Legacy.exe`, Explorer/Пуск/панель задач недоступны.
4. Проверьте запуск любого выбранного Win32 EXE, один экземпляр, перезапуск после закрытия и ручное разворачивание после сворачивания.
5. Проверьте Win, Win+R/E/X/S/D, Alt+Tab, Ctrl+Alt+Tab, Ctrl+Shift+Esc; Win+L должен работать.
6. Проверьте обычный ввод текста в приложении и логина/пароля в окне разблокировки.
7. Неверный пароль и обычный пользователь должны получить отказ; локальный Administrators — ограниченную admin-сессию.
8. Проверьте остановку/запуск надзора, смену приложения, открытие рабочего стола и автоматический таймаут admin-сессии.

## Restore/Undo

1. Из административной УЗ выполните dry-run `restore`, затем `restore --apply`.
2. Войдите оператором повторно и проверьте обычный Explorer, Пуск и панель задач.
3. Сравните shell, политики и DACL с backup.
4. Сравните службы, драйверы и автозагрузку с baseline: отличий из-за киоска быть не должно.
5. Убедитесь, что процессов Legacy и keyboard hook не осталось.
6. Проверьте, что административная УЗ работает обычно.
7. Сохраните логи без паролей, затем верните снимок VM.

Платформа получает статус `Verified` только если все пункты пройдены и Restore/Undo вернул baseline. Иначе результат остаётся `Targeted` или `Failed` с описанием причины.
